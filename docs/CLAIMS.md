# Claims

Every promise Lax makes about privacy and security, the code that keeps it, and
the test that checks it. If a claim has no test, it says so.

This page is updated in the same pull request that implements or changes a claim.
The idea comes from [Mason](https://github.com/Baltsar/mason/blob/main/docs/CLAIMS.md).

| Claim | Guardrail | Code | Test |
|---|---|---|---|

| Private browser windows are never captured | §4 | `Exclusions::check_window` in `src-tauri/src/exclusions.rs`, by title markers in several languages (Safari adds ", privat surfning" / ", Private Browsing"). Both run in `Capturer::tick` (`src-tauri/src/capture.rs`) before any content is read. | Password managers are never captured | §4 | `Exclusions::check_app` in `src-tauri/src/exclusions.rs` (also system password prompts and Lax itself) | `exclusions::tests::password_managers_are_never_captured`, `re_enabling_cannot_unlock_the_never_tier` |
| Exclusions are checked before content is read | §4 | `Capturer::tick` in `src-tauri/src/capture.rs`: app, then title (and Safari's address field), then the host of each web area, before any text in it. | Only the host of a URL is stored | §4 | `site_from_url` in `src-tauri/src/site.rs` keeps only the host of `http`/`https` addresses; capture stores only its result. Toolbars, which hold the address field, are never read, and in browsers only the page (web area) is read. A browser window title that is an address (pages without a title) is replaced by its host (`title_without_address` in `src-tauri/src/capture.rs`). `Store::insert` drops a site that isn't a bare host | `site::tests`, `capture::tests::normal_safari_windows_keep_only_the_host_and_the_page`, `browsers_read_only_the_page`, `browser_titles_that_are_addresses_keep_only_the_host`, `stored_captures_are_redacted_and_keep_only_the_host` |
| Secrets are redacted before they are stored | §4 | `redact()` in `src-tauri/src/redact.rs` masks passwords, keys, tokens, private keys, card numbers and personal identity numbers. `Store::insert` in `src-tauri/src/store.rs` runs it on every title and text, so nothing is stored unredacted | `redact::tests`, and `store::tests::secrets_are_redacted_before_they_are_stored` |
| While paused, nothing is read | §4 | Pause state in `src-tauri/src/pause.rs` (`Pause::is_paused`), saved in the database and restored at startup before anything else runs, so a pause survives a restart. `Capturer::tick` in `src-tauri/src/capture.rs` checks it before every step and every element, and the capture loop drops what was read if a pause began meanwhile, including content held back by `Throttle` | Pause, resume and expiry: `pause::tests`. Surviving a restart: `store::tests::pause_survives_a_restart`, `a_damaged_pause_keeps_capture_paused`. Capture: `capture::tests::while_paused_nothing_is_read`, `a_pause_during_reading_stops_it`, `a_pause_drops_what_was_held`. The loop turning a capture into a pause when a pause began during the read has no automated test |
| Everything captured can be seen in the app | §1 | The window lists every stored capture, newest first, with full-text search and the whole text on request: `src/Viewer.tsx`, backed by `recent`, `get` and `search_hits` in `src-tauri/src/store.rs` through the commands in `src-tauri/src/viewer.rs`. Captured text is rendered as text only, never as HTML | `store::tests::recent_lists_newest_first_and_continues`, `recent_shows_only_the_start_of_long_text`, `get_returns_all_the_text`, `search_hits_mark_the_matched_words`, `viewer::tests::the_web_ui_never_renders_text_as_html`. The window itself has no automated test yet |
| Lax warns when FileVault is off | §6 | `filevault_enabled` in `src-tauri/src/filevault.rs`, shown by `FileVaultWarning` in `src/App.tsx` | `filevault::tests` (reading the status). The banner itself has no automated test yet |
| The data folder and database are private to the user | §6 | `prepare_data_dir` (`0700`) and `Store::open` (`0600`) in `src-tauri/src/store.rs` | `store::tests::data_folder_is_private`, `existing_data_folder_is_made_private`, `database_file_is_private` |
| Raw captures expire automatically (default 90 days) | §4 | `Store::expire` in `src-tauri/src/store.rs`, run at startup and every hour by `src-tauri/src/expiry.rs` | `store::tests::expire_deletes_captures_older_than_the_retention`, `retention_*` |

From the window: the last 15 minutes, hour or 24 hours, a time range, an app, or everything including the logs (`src/Forget.tsx`, commands in `src-tauri/src/forget.rs`), each confirmed once more | `store::tests::forgotten_text_is_gone_from_the_files_on_disk`, one test per kind of forget, `captures_read_before_a_forget_are_refused_after_it`, `forgetting_an_app_refuses_its_held_captures`, `forget::tests` (requests from the window, nonsense refused). The window itself has no automated test yet |
